# Phase F4 — The visual signature stamp

**Prerequisite reading:** `docs/SPEC.md` in full, with §13 as the core of this assignment, then `docs/decisions.md` in full.

**Prerequisite phase:** F3 complete, including the real-fixture tests. All three real documents must parse completely and the already-signed-document test must pass against a genuine prior signature.

**Goal of this phase:** a signature can carry a visible stamp on the page, rendered correctly for Serbian names in both Latin and Cyrillic script.

**Explicitly not in this phase:** no windows, no tray, no drag and drop, no HTTP. The stamp is produced by the engine and controlled by CLI flags.

**Exit condition:** `liro-bridge sign --stamp` produces a document whose visible stamp renders correctly in Adobe Reader, with a Cyrillic name, on all three real fixtures.

---

## 1. Why this is small but not trivial

The geometry is already decided and measured. What makes this phase real work is font embedding: the PDF base-14 fonts cannot render Cyrillic, nor č ć đ š ž. A Serbian name almost always contains at least one of these, so a stamp that falls back to Helvetica renders a row of blanks or garbage.

Get the font right and the rest of this phase is arithmetic.

---

## 2. Geometry — fixed values

| Property | Value |
|---|---|
| Width | 190 pt, fixed |
| Margin from page edge | 24 pt |
| Logo | 36 × 36 pt |
| Internal padding | 4 pt |
| Height by line count | index = number of lines: `[44, 44, 46, 56, 72]` |

Height grows with the number of lines actually drawn, so a two-line stamp is not a four-line stamp with empty space.

Default position is the bottom-right corner. Other corners and explicit coordinates are supported through an options struct. A visual position picker is F-later, not now.

### 2.1 Page box resolution

Read `/MediaBox` from the target page. **If it is not on the Page object, follow the `/Parent` chain** — `MediaBox` is very commonly inherited from the `Pages` node rather than set per page. Fall back to A4 only when it is genuinely absent everywhere.

Respect `/Rotate` if present. A stamp placed in the bottom-right of an unrotated coordinate system lands somewhere else on a rotated page, and rotated pages are common in scanned documents.

Works on any page, not only the first.

## 3. Font embedding

**Package:** `internal/pades/appearance`

### 3.1 What to embed

A subsetted **NotoSans** as `Type0` / `CIDFontType2` with `Identity-H` encoding.

Structure required in the PDF:

```
/Type0 font
  /Subtype /Type0
  /BaseFont /AAAAAA+NotoSans        (six-letter subset tag, uppercase)
  /Encoding /Identity-H
  /DescendantFonts [ <CIDFontType2> ]
  /ToUnicode <CMap stream>          (required — see §3.4)

/CIDFontType2
  /Subtype /CIDFontType2
  /CIDSystemInfo << /Registry (Adobe) /Ordering (Identity) /Supplement 0 >>
  /FontDescriptor << ... /FontFile2 <subsetted TTF stream> >>
  /W [ ... glyph widths ... ]
  /DW 1000
  /CIDToGIDMap /Identity
```

### 3.2 Subsetting

The subset contains exactly the characters the stamp can draw. That is: ASCII, the Serbian Latin letters (č ć đ š ž and their capitals), the full Serbian Cyrillic alphabet in both cases, digits, and the punctuation the stamp uses.

Generate the subset **at build time**, not at run time. Commit the subsetted TTF as an embedded asset with `//go:embed`. Runtime subsetting would mean shipping a font parser, which is a large surface for no benefit.

Record the exact character set in a committed file (`internal/pades/appearance/charset.txt`) so a future change is reviewable.

### 3.3 Text to CIDs

`Identity-H` means each glyph is addressed by a two-byte glyph index, written as a hex string:

```
<00480065006C006C006F> Tj
```

Build a `rune → GID` table at build time alongside the subset, and embed it.

**If a character is not in the subset, return a clear error naming the character and its code point.** Do not draw nothing, do not substitute, do not fall back to a question mark. A silently missing character in a legal document's stamp is worse than a failed signing operation.

### 3.4 `/ToUnicode`

Required, not optional. Without it the stamp text cannot be selected, copied or searched, and — more importantly — accessibility tools read nothing. Emit a CMap stream mapping each GID back to its Unicode code point.

### 3.5 Widths

`/W` must carry the real advance width of every glyph in the subset, in 1000-unit text space. Wrong widths produce visibly uneven spacing. Extract them at build time from the font and embed them alongside the GID table.

## 4. The logo

Two streams: the RGB image and an alpha mask, both Flate-compressed, referenced through `/SMask`.

```
/XObject
  /Subtype /Image
  /Width  N  /Height M
  /ColorSpace /DeviceRGB
  /BitsPerComponent 8
  /Filter /FlateDecode
  /SMask <alpha image object>
```

Embed both as generated Go source or as `//go:embed` assets. The logo is fixed; do not make it configurable in this phase.

## 5. Content

Up to four lines. Which lines appear depends on what is available and on options:

| Line | Source | Default |
|---|---|---|
| Label | "Digitally signed by" / "Digitalno potpisao" / "Дигитално потписао" | shown |
| Signer name | `givenName` + `surname` from the certificate | shown |
| Reference | caller-supplied document reference | shown when supplied |
| Serial and time | certificate serial, timestamp time | shown |

### 5.1 The name comes from givenName and surname, never from CN

SPEC §11.7. Real CN values are:

```
"ВЕЉКО СТАНОЈЕВИЋ 011445479 Sign"
"Zoran Milovanović 246275"
"Redžvel Mešković 200094362"
```

A stamp built from CN would print the CA's internal number and, for MUP, the literal word `Sign`. All three certificates carry `givenName` (2.5.4.42) and `surname` (2.5.4.4) separately. Use those.

### 5.2 The identity document number is not shown by default

SPEC §13.5. It is personal data appearing on a document that goes to third parties. Available as an option, never the default.

The national identity number (`PNORS-…`) must be impossible to place in a stamp at all — the classification layer from F1 already discards it, and nothing in this package may reach around that.

### 5.3 Localisation

Stamp text follows the configured locale: `sr-Latn`, `sr-Cyrl` or `en`. The signer's name is **not** localised — it is rendered in whatever script the certificate carries, which is Cyrillic for MUP and Latin for the others, regardless of interface language (SPEC §9.3).

### 5.4 Overflow

If a name is too long for 190 pt at the chosen size, reduce the font size in one step, then truncate with an ellipsis. Do not widen the stamp, do not wrap to another line, do not overflow the box.

## 6. Separation from the invisible path

Stamp generation is invoked **only** when a stamp is requested. The default behaviour — an invisible signature with `/Rect [0 0 0 0]` — must be byte-for-byte unchanged when no stamp is requested.

Prove it: a test that signs the same document with and without the stamp flag, using a fixed key and timestamp, and asserts the no-stamp output still matches the F3 golden file exactly.

---

## 7. CLI

```
liro-bridge sign --in x.pdf --out y.pdf --thumbprint <hex>
    [--stamp]                          off by default
    [--stamp-position bottom-right|bottom-left|top-right|top-left]
    [--stamp-xy <x>,<y>]               explicit, in points
    [--stamp-page <n>]                 default 1; -1 means last
    [--stamp-reference <text>]         the reference line
    [--stamp-show-document-id]         off by default, see §5.2
```

`--stamp-xy` and `--stamp-position` are mutually exclusive; supplying both is an error.

## 8. Tests

- Stamp renders on all three real fixtures; each output parses and both signatures verify.
- **Cyrillic name from the MUP certificate renders correctly** — assert the CID sequence matches the expected glyph indices for the Cyrillic string.
- Latin name with č ć đ š ž renders correctly.
- A character outside the subset produces a clear error naming the character.
- All five height values are exercised, one per line count.
- Every corner position lands inside the page box.
- Explicit coordinates land where specified.
- Inherited `/MediaBox` from `/Parent` is resolved.
- A rotated page places the stamp visibly correctly.
- Long name is reduced then truncated, never overflowing.
- **Without `--stamp`, output matches the F3 golden file byte for byte.**
- `/ToUnicode` is present and maps every drawn glyph.
- No stamp output contains 13 consecutive digits.

### 8.1 Manual acceptance

- Adobe Reader shows the stamp at the expected position on all three fixtures.
- Cyrillic renders as Cyrillic, not as blanks or boxes.
- Text in the stamp can be selected and copied in Adobe.
- The stamp does not cover meaningful content on a real financial statement.

---

## 9. Decisions to record

- Font subsetting happens at build time, not run time, and why.
- Missing glyphs fail loudly rather than substituting.
- `/ToUnicode` is mandatory.
- The name is built from `givenName` and `surname`, with the three real CN values as evidence.
- The identity document number is opt-in, and the national identity number is unreachable.
- `/Rotate` handling.
